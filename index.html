Before relying on this dashboard

RESEARCH PROTOTYPE
  • The official market settles using Chainlink’s BTC/USD 60-second TWAP. The price-to-beat panel uses Polymarket’s matching TWAP feed, with exact opening capture or a clearly labeled manual reference. Coinbase is used only for the separate spot display, historical chart and candle heuristic.
  • The historical research models did not establish a dependable predictive edge. Neither has been promoted into this site.
  • This GitHub Pages edition is a separate, simplified candle-only baseline: browser-candle-baseline-v1. It is not a port of the Python strategy. Its forecasts are not the live price-to-beat comparison.
  • APIs can be unavailable, browser-blocked or rate-limited. Stale prices, comparisons, quotes and drafts are suppressed. Keep your computer’s clock synchronized.
  • This site never requests a wallet, seed phrase, API key, login, payment or order. External market links leave this site.
